# GTM Funnel Analytics + Claude Self-Serve Agent

A portfolio project pairing growth/GTM data science (funnel analysis, A/B-style
causal inference, propensity modeling) with a Claude-powered natural-language
agent that lets a non-technical stakeholder query the results in plain English.

It's built to mirror the shape of real freemium-SaaS growth work — top-of-funnel
channel measurement, a difference-in-differences read on a product experiment,
and a lifecycle propensity model — the same toolkit used to run acquisition and
upsell measurement programs, plus a self-serve GenAI layer on top so
non-technical stakeholders can query results without waiting on a data pull.

**All data here is synthetic**, generated by `01_generate_data.py` from a
seeded random process. No employer or proprietary data is used anywhere in
this repo — it exists purely to demonstrate the methodology end to end.

## What it demonstrates

- **Funnel / GTM analytics** — traffic → signup → activation conversion by
  paid channel and customer segment (`02_funnel_and_did_analysis.py`, part A)
- **Causal inference** — a difference-in-differences regression evaluating
  whether a redesigned upsell flow actually moved conversion, versus just
  looking at a before/after average (`02_funnel_and_did_analysis.py`, part B)
- **Predictive modeling** — a gradient-boosted upgrade-propensity model with
  evaluation metrics and a ranked outreach list (`03_upgrade_propensity_model.py`)
- **Applied GenAI / LLM engineering** — a Claude tool-use agent that answers
  natural-language questions by calling the analytics functions above, so
  every answer is grounded in a real computed number instead of a guess
  (`04_llm_agent.py`)

## Project layout

```
01_generate_data.py            synthetic data generator
02_funnel_and_did_analysis.py  channel funnel + DiD experiment analysis
03_upgrade_propensity_model.py gradient boosting propensity model
04_llm_agent.py                Claude tool-use natural-language agent
data/                          generated input CSVs
output/                        generated charts, models, and result files
```

## Running it

```bash
pip install -r requirements.txt

python 01_generate_data.py
python 02_funnel_and_did_analysis.py
python 03_upgrade_propensity_model.py

export ANTHROPIC_API_KEY=sk-ant-...
python 04_llm_agent.py "Which paid channel converts best for new customers?"
python 04_llm_agent.py "Did the upsell redesign actually work?"
python 04_llm_agent.py "Who are the top 5 customers to target for an upgrade push?"
```

Or run `python 04_llm_agent.py` with no arguments for an interactive prompt.

## Sample result

The DiD regression recovers a **+4.5-point lift** in free→premium conversion
for the treatment group post-launch (p < 0.001, robust SEs) — while a naive
before/after comparison on the treatment group alone would have overstated
the effect, since it doesn't net out the control group's own trend. See
`output/did_regression_summary.txt` after running the scripts.

## Why this project

Built as a hands-on demonstration of the intersection of causal inference,
predictive modeling, and applied GenAI/LLM engineering — using Claude Code as
the primary build tool, the same way Claude Code and Cursor are used for
day-to-day agentic development work.
